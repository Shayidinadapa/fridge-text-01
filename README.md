A [make.fun](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) entry for the bounty **"The 3AM Fridge Text"**: a program that writes the one line a smart fridge would text its owner at 3am.

## The line

> 3am. I've kept your food cold all night and you haven't thanked me once. Not once. I'm telling the toaster.

The fridge has been awake all night, has feelings, and has finally decided to say something about it — to its owner, and to the toaster.

## Run

```sh
node main.ts
```

Requires Node 22 or later. The program writes the single line (at most 140 characters, one line, no control characters) to `/output/entry.txt`, or to the directory named by `MAKEFUN_OUTPUT_DIR` / `OUTPUT_DIR`.
